## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL database (Supabase)
- Git

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/tradeet.git
   cd tradeet
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment setup**
   ```bash
   cp .env.example .env.local
   # Configure your Supabase credentials
   ```

4. **Database setup**
   ```bash
   npm run db:push
   npm run seed:faker
   ```

5. **Start development server**
   ```bash
   npm run dev
   ```

6. **Run tests**
   ```bash
   npm run test
   ```

### Deployment
- **Vercel**: One-click deployment with automatic CI/CD
- **Database**: Supabase for production database
- **Domain**: tradeet.app (SEO-optimized for Ethiopian market)
